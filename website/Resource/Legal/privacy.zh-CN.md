# 隐私与数据处理说明

拟定版本 · 2026-10-08

本说明介绍 MewMent 的免费使用规则与数据处理方式。正式发布时将列明生效版本；本网页不收款，也不要求提供支付信息。

- 工作内容保存在你的设备上

- 云端处理账号、界面偏好与必要安全信息

- AI 请求直接交给你选择的服务商

## 1. 三条清楚的数据边界

本机：日程、项目、附件、摘要、聊天历史和备份保存在你的设备上。账号云端：处理注册登录、身份核验、必要安全记录，并同步语言、主题、字体、布局和日历显示等基本界面偏好。你选择的 AI 服务：接收完成摘要或对话所需的文本与认证。

“工作内容不上传到 MewMent 账号云端”不等于“设备从不联网”。登录、界面偏好同步、你启用的 AI API，以及你主动打开的外部链接，都可能产生相应网络请求。

## 2. 本机工作资料

日程、任务、子任务、Project、执行时间、会话摘要和 AI 对话等由软件在本机按账号隔离保存。启用的 Agent 会话目录被只读扫描；记录可能包含来源标识、工作区路径、摘要和时间依据。

MewMent 账号云端不保存这些工作正文，也不以收集这些内容为目的建立云同步。你自行导出、复制、备份到其他位置，或主动向作者发送资料时，会形成由你选择的新数据去向。

## 3. 账号云端处理什么

为提供账号服务，系统处理用户名、显示名、账号标识、登录验证所需的受保护凭据与会话状态、账号角色与状态、必要的账号与授权历史、设备标识及安全记录。账号云端同时保存预先限定的基本界面偏好，用于你在不同电脑上恢复相同的显示设置。网络基础服务也可能产生 IP、时间等连接与安全记录。

同步字段仅限软件预先定义的界面选项、数值和颜色；不包含任务或项目数据、附件、会话正文、API 密钥或接口配置、本机路径、日历备注、MCP 密钥或任意文本。这些账号与偏好数据仍可能与个人关联，不能被表述为“完全不涉及个人信息”。账号云端不充当模型请求代理。

## 4. API Key 的保存与使用

API Key 会保存在你的电脑的系统凭据库中；Windows 使用 Credential Manager。普通配置记录与界面使用掩码，不将完整密钥上传到 MewMent 账号云端。

调用模型时，客户端按你选择的协议，将密钥作为对应服务的认证信息发送到你填写的服务地址。请确认地址可信，并在服务商处设置合适权限、额度及撤销规则。本网页的配置演示仅使用无效示例，不接受真实密钥。

## 5. 摘要与 AI 对话

启用会话摘要后，软件会把受长度限制并按实现做脱敏处理的相关会话片段交给你选定的 Agent/API，生成内容摘要。时间依据来自来源记录，而不是根据摘要长度推测。

AI 对话会将消息、上下文和你授权操作所需的信息交给所选模型。使用的服务商、服务地点、保留期限、训练用途及安全措施由该服务商政策决定；MewMent 不保证第三方“零留存”。本机 Agent 是否联网，也由它自身配置决定。

你可以更换或停用提供方、关闭不需要的扫描来源，并在原服务商撤销密钥。只是不启用 AI，不影响普通任务与日程功能本身。

## 6. 保存期限、设备与删除

本机资料由你通过软件功能、备份与设备管理进行保留或删除。停止使用软件不会主动删除这些本机文件。软件备份不包含系统凭据和登录 token；重装后可能需要重新配置凭据。

账号与必要的授权历史、设备变更和安全记录，按提供服务、保障安全及履行法定义务所必需的期限保留。不能承诺注销后所有历史立即清除。需要更换设备绑定或了解账号资料的保留与删除方式，可通过邮箱联系作者。

## 7. 反馈、网站与第三方链接

联系作者时，你主动提供的邮箱、问题描述、截图或样例只应用于沟通与处理相应请求。请先移除密钥、密码和不必要的私人正文；作者不应以支持为由索取完整 API Key。

当前官网不设置分析追踪脚本、在线 API Key 表单或会话上传接口；只在浏览器中保存语言偏好。访问公开托管的网站或打开第三方链接，仍会向相应主机发出正常访问请求；邮件和外部网站适用各自的隐私规则。

## 8. 你的选择与联系渠道

你可以选择是否启用 AI、扫描哪些来源、使用哪个服务商、是否导出或发送资料，以及何时替换或撤销密钥。可以发送邮件至 thehomeofsea@gmail.com，提出查阅、更正、账号注销或删除请求，按适用法律及必要的身份验证处理。

这份说明随已实现的数据流维护。若未来增加工作内容云同步、收集更多资料或改变处理目的，必须另行披露并在必要时取得明确同意，不能把这些变化默认为现有授权。
