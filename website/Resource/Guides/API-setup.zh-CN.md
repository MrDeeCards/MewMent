# MewMent · 接入你选择的 AI。

先验证 API，再分别用于会话总结和 AI 对话。配置、数据流向和常见问题，都在这里。

请在软件内填写真实密钥。本页只展示虚构配置，不接收真实 API Key。

## 摘要总结

### 1. 准备你自己的模型服务

在所选服务商或自建网关取得 Base URL、API Key、精确模型 ID 和受支持的协议。确认账号余额、权限及模型可用性。

- MewMent 免费使用；模型服务的用量费用由服务商另收。

- API 可以独立配置，无需先安装或验证本机 Agent。

- 选择第三方 API 后，摘要文本会发送给该服务商。

### 2. 进入“会话总结助手”

在 MewMent 主窗口打开设置，找到“AI 会话时间归档”，进入“会话总结助手（智能助手 / API）”，选择“添加 API 摘要服务”。

- 已有 API 配置可在已验证服务列表中编辑或重新验证。

- “会话来源”负责找到记录，API 执行器负责生成摘要，两者分别设置。

### 3. 填写名称、协议、地址、模型和密钥

名称用于自己辨认；协议应与服务商一致。Base URL 填服务基础地址，模型填写精确 ID，API Key 只在软件内输入。

- 标准 /v1 接口通常无需填写 Endpoint 覆盖。

- 非标准路径在“高级协议设置”中填写以 / 开头的完整路径。

- Anthropic Messages 可按服务商要求填写 Anthropic Version。

### 4. 点击“验证并保存”

软件向填写的服务发送一条随机测试消息，收到正确模型回复后才保存配置。仅 HTTP 成功、连通地址或收到错误页，都不等于验证通过。

- 测试可能消耗服务商额度。

- 密钥保存到本机系统凭据库，界面仅显示掩码。

- 失败时查看错误，再按“常见问题”检查，避免反复盲试。

### 5. 明确选用已验证的 API

在已验证服务列表中点击“用作会话总结助手”，或者在“当前会话总结助手”中选择它，确认界面显示正在使用该服务。

- 验证并保存 ≠ 已经切换。

- 不同摘要服务可以保留在列表中，但当前摘要执行器要明确选定。

- 在 AI 对话里选择另一模型，不会替你更改摘要选择。

### 6. 勾选要整理的本地会话

回到“会话来源与自动整理”，开启需要的来源并保存设置，再点击“立即扫描”。标准目录会自动检测，自定义安装或特殊 WSL 位置可补充路径。

- 支持整理 Codex、Claude Code、OpenCode、OpenClaw、Hermes、Pi 等来源。

- API 配置正确，不等于电脑上已经存在可扫描的会话。

- 仅启用的来源会进入扫描；摘要需要可处理的新内容。

### 7. 在 AI 日程里核对内容和时间

切换到 AI 视角，展开会话记录，核对摘要、原始位置、日期与活动时间。它们用于回顾哪天做了什么、花了多久。

- 摘要解释协作内容；时长以来源证据为依据。

- 不同来源可能显示精确计时或推断计时。

- 无新消息时，不应重复调用模型生成相同摘要。

## AI 对话

### 1. 准备能对话和调用工具的模型

准备 Base URL、API Key、模型 ID 与协议。普通对话需要文本能力，聊天式任务管理还需要服务和模型兼容所选协议的工具调用。

- 聊天与摘要可共用配置，也可选择不同服务。

- 确认模型/API 用量由你与服务商单独结算。

- “本地软件”不代表所选模型一定离线运行。

### 2. 从 AI 助手进入模型/API 设置

点击主窗口左上角的猫咪 Logo 打开 AI 助手，使用模型区域的设置按钮进入“添加模型 API”。也可以复用已经验证过的 API 条目。

- 填写字段与摘要配置相同。

- 这里接入的是软件内聊天模型，不是对外提供的 MewMent MCP 接口。

### 3. 先确认真实回复，再保存

填写服务名称、协议、Base URL、模型 ID 和 API Key，点击“验证并保存”。成功后返回 AI 助手；验证失败则检查地址、密钥、额度和协议。

- 新增必须提供 Key；编辑时留空可复用本机凭据。

- 摘要选择与聊天选择独立；保存配置不会替你决定两个用途。

### 4. 在对话中选择提供方和模型

在助手的提供方下拉框选择已验证服务，再选择模型。可刷新模型列表；服务未提供模型目录时，可使用“自定义模型 ID”。

- 使用服务商给出的精确 ID，不能只填展示名称。

- 配置改变后按软件提示新建对话，以使用新的服务配置。

- 思考等级等选项仅在对应模型支持时出现。

### 5. 先问候，再尝试一个明确的安排

先发送一句简单问候确认可回复，再尝试“帮我为明天安排 30 分钟整理资料”。检查生成的任务、日期和执行结果。

- 真实请求会发给你选择的服务商。

- 日程管理过程中，重要操作遵循授权和确认流程。

- 主助手与悬浮聊天共用当前会话。

### 6. 按需要切换、编辑与撤销

在助手中选择另一提供方，或回设置编辑服务并重新验证。遇到错误先检查密钥权限、额度、协议和工具调用兼容性。

- 不要在网站或反馈邮件中发送完整 Key。

- 删除本机配置不等于在服务商处撤销密钥。

- 聊天正常但不能改日程时，检查工具调用支持及操作授权。

## 每个字段应该填什么

### 名称

便于识别的服务名称，如“我的摘要服务”。

### 协议模式

选择服务商支持的 Responses、Chat Completions 或 Anthropic Messages；不能仅按模型品牌猜测。

### Base URL / 服务地址

填服务基础地址，例如 https://api.example.com/v1；不要填聊天网页地址、完整 /chat/completions 路由，或含密钥/查询参数的 URL。

### 模型

服务商提供的精确模型 ID；须有使用权限。示例 your-model-id 不能直接使用。

### API Key / 访问密钥

在软件内填写服务商密钥。新建必填；编辑留空保留旧密钥。只写入本机系统凭据库。

### Endpoint 路径覆盖

通常留空。若服务不是标准路径，填写从站点根开始的路径，如 /chat/completions 或 /v1/messages；它替换路径，不追加到 Base URL；不能含 ? 或 #。

### Anthropic Version

仅 Anthropic Messages 使用；默认 2023-06-01，若网关要求其他值，按服务商说明填写。

不填 Endpoint 覆盖时，Base URL 路径以 /v1 结尾会直接追加协议路径；只有域名时会补 /v1；其他前缀会追加 /v1 再加协议路径。远程服务必须使用 HTTPS，HTTP 仅允许 localhost、127.0.0.1 或 ::1。

## 选择协议示例

### OpenAI Responses

```text

Base URL: https://api.example.com/v1

Protocol: open_ai_responses

Model: your-model-id

Endpoint: https://api.example.com/v1/responses

```

### OpenAI Chat Completions

```text

Base URL: https://api.example.com/v1

Protocol: open_ai_chat_completions

Model: your-model-id

Endpoint: https://api.example.com/v1/chat/completions

```

### Anthropic Messages

```text

Base URL: https://api.example.com/v1

Protocol: anthropic_messages

Model: your-model-id

Endpoint: https://api.example.com/v1/messages

```

此处 example.com 和 your-model-id 都是占位符；请替换为服务商提供的真实服务地址及精确模型 ID。

## 修改、换密钥或停用

在已验证服务列表点击“编辑”，修改后重新验证。编辑时 API Key 留空会沿用本机原凭据；填写新 Key 才会替换。验证失败不会覆盖原配置。删除服务前先为摘要或聊天更换提供方；需要彻底撤销密钥时，到原服务商控制台撤销。

## 也可以选择本机 Agent

在会话总结助手中选“使用本地智能助手”，按查找 → 真实验证 → 选用操作。它与 API 是两条独立配置路线。聊天助手当前支持经过适配的 Codex / Claude Code；并非所有可归档来源都能用作聊天执行器。本机 Agent 也可能调用自己的云模型。

## 常见问题

### 401 / 403：密钥或权限错误

检查 Key 是否有效、是否粘贴完整、账号是否允许使用该模型；确认 Key 与 Base URL 属于同一服务。不要把网页登录密码当作 API Key。

### 404：找不到接口

检查协议是否被服务商支持，Base URL 是否重复包含 /v1 或完整接口后缀。非标准接口使用 Endpoint 路径覆盖。

### 429、余额不足或限流

查看服务商余额、额度和速率限制，等待后重试。MewMent 免费使用，但不提供第三方模型额度。

### 能连上但验证仍失败

服务必须返回正确的随机测试内容；错误页面、空回复、截断输出或不兼容协议都可能失败。检查模型和网关兼容性。

### 已经保存，但没有生成摘要

先显式选用“当前会话总结助手”，再启用来源、保存设置并扫描。检查本机是否有近期可处理会话；没有新增消息时可能不会再次摘要。

### API 能聊天，但不能管理日程

检查模型及网关的工具调用支持、所选协议和应用中的授权提示。简单文本回复验证不保证所有工具操作可用。

### 本机 Agent 没有被发现

先确认工具已安装、登录并能自行工作；重新查找，必要时补充安装位置或 WSL 路径。归档来源与摘要执行器需要分别配置。

### 修改密钥或配置以后怎么办

编辑后重新验证；留空 Key 会沿用旧凭据。服务地址或协议变化时按提示新建对话。撤销泄露密钥应在原服务商控制台完成。
